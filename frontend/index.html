Website ini digunakan untuk melihat, mencari, menambahkan, mengubah, dan menghapus data pelanggan.

Cara Menggunakan Website

Menambah dan Mengubah

Buka halaman Manipulasi Data, isi seluruh kolom, lalu simpan. Untuk mengubah data, tekan tombol Edit pada baris pelanggan.

Mencari Pelanggan

Gunakan kolom pencarian pada bagian Daftar Pelanggan. Pencarian dapat berdasarkan nama atau email.

Menghapus Pelanggan

Tekan tombol Hapus pada baris pelanggan dan konfirmasi tindakan tersebut.
